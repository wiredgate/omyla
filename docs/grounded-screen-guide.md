# 実画面を見て教える: Windows preview

Windows版の小さなボタンを開いて対象モニターを選び、依頼を書いて「画面を見て教える」を押す。選んだ画面を一回だけJPEGで取得してCloudflare Workers AIへ送る。AIは画面内の位置を0〜1の正規化座標で返し、Electronの透明なクリック透過ウィンドウが対象モニターの実画面上へ丸・矢印と短い説明を描く。「次の案内」「案内を消す」で進む。通常はユーザーがクリックする。Windows版では、ユーザーが「AIがこの位置をクリック」を押した場合に限り、その一手を実行する。実行直前に画面を再取得し、対象付近が変化していたり案内から60秒以上経過していたりすれば実行を止める。クリック後は案内を消し、新たな操作には再撮影を要する。

- 画像送信は明示操作時のみ。従来の「画像確認」はローカルのみ。画像、案内結果はサーバーに保存しない。
- 送信元画面の座標と寸法を返答時に照合し、画面構成が変わっていたら案内しない。モデルの座標と文面も検証する。
- 公開プレビューは画像1MB以下、依頼800文字以下、1 IPで1日5回、全体で1日30回に制限する。匿名公開のためこの制限は課金保証や強い認証ではない。
- `VISION_MODEL`は運営側の設定。既定は`@cf/google/gemma-4-26b-a4b-it`。対応する視覚モデルへの切り替えは案内役のIdentityとは独立。Meta Llama Visionを選ぶ場合は運営者が利用条件を確認し、Cloudflareで必要な初回同意を済ませる。
- モデルが画面上の印や座標を誤る可能性がある。画面が変わったら再度ボタンを押して撮影する。常時監視・カメラ映像・スマホへの実画面描画・連続する自律クリックはこの版には含まない。
- 製品化にはログイン、ユーザーごとの使用量計測・決済、プライバシー保護の追加制御、画面変化の継続的な検知が必要。
